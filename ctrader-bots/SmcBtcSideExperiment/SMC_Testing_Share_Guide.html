SMC Testing — Share Guide

cTrader side experiment for BTCUSD (m15) with H4 bias. Not a replacement for live Challenge stack (UltimateTrader + ADX H4 / Test G).

1. What the bot does

Core flow (price-action SMC on OHLC):

  • H4 Break of Structure (BOS) sets directional bias
  • m15 liquidity sweep
  • Change of Character (CHoCH)
  • Order-block retest entry

Also includes week drawdown brake (default 3.5%) and dollar risk sizing.

2. News pause

Blocks new entries around high-impact events. Open trades are left alone.

  • Enabled by default
  • Pause before: 90 minutes
  • Resume after: 45 minutes
  • Event toggles: NFP / FOMC / CPI / Core PCE
  • Built-in approximate calendar + Extra Events UTC for exact times

Extra Events UTC format:

yyyy-MM-dd HH:mm|Title;yyyy-MM-dd HH:mm|Title Example: 2026-07-29 18:00|FOMC;2026-08-01 12:30|CPI

3. Optimisable SL and TP

Same ranges as the G weekly hunt (set step in Optimizer UI):

  • SL Mode: Percent (default) or OrderBlock
  • SL Percent: optimise 0.6 → 1.0, step 0.1
  • TP Risk Multiplier: optimise 1.8 → 2.8, step 0.2

In Optimizer: tick SL Percent and TP Risk Multiplier, set min/max/step, run Grid.

4. Level-2 order book (DOM)

Optional imbalance filter using cTrader MarketData.GetMarketDepth.

  • Use Level-2 Imbalance Filter: OFF by default
  • DOM Levels to Sum: top N bids/asks (default 5)
  • Min Bid/Ask Imbalance Ratio: e.g. 1.2

When ON: before entry, sums top N bid vs ask volume. Longs need bids dominating; shorts need asks dominating.

5. What if Level-2 is not available?

Nothing breaks — entries still use normal SMC rules. If the filter is OFF, DOM is never used. If the filter is ON but depth is empty (common on BTC/prop feeds and in all backtests), the bot logs BidLevels=0 AskLevels=0 and skips the check (“DOM empty — skipped”). Missing L2 does not block trades and does not change SL/TP. A real imbalance gate only applies live when the broker publishes Depth of Market on BTCUSD.

6. Install (cTrader)

  • Open cBot named SMC Testing in Automate
  • Ctrl+A, Delete (wipe the template completely)
  • Paste entire SMC_Testing.cs, then Build
  • Attach BTCUSD m15 · Bias timeframe Hour4

CS1022 / CS0106 usually means the code was pasted inside leftover template code — wipe the file first.
