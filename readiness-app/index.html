    Apple Health import
    
        
    A web app cannot link directly to Apple Health (that requires a native iOS app). Instead, export your data: iPhone Settings → Health → Export All Health Data, unzip in Files, then upload export.xml here. Processing happens entirely on your device.
    
        
        
    
      
    

      
    
        
    Screenshot AI (optional)
    
        
    For best screenshot reading, add an OpenAI API key. Stored only on this device. Without it, basic OCR is used (less accurate). Screenshots are sent to OpenAI only if you add a key and tap Analyse.
    
        
      
    

      
    
        
    Secure sharing
    
        
    Share reports with people you trust. Data is encrypted with a passphrase before export — send the file and passphrase separately (e.g. Signal). No cloud account needed; only someone with the passphrase can read it.
    
        
        
    
          
          
        
    
      
    

      
    
        
    Calibration
    
        
    After travel or routine changes, set a calibration start date. The app treats the next 14 days as baseline-building rather than making strong conclusions.
    
        
        
        
      
    

      
    
        
    Data
    
        
    All data stays in your browser (localStorage). Export for backup.
    
        
    
          
          
        
    
      
    

      
    
        
    Important
    
        
    Recovery scores are not medical diagnoses. Compare metrics to your own trends, not universal "good" or "bad" HRV values. Bevel Recovery and OutPerform Readiness use different algorithms — treat each as an internal trend, not as equivalent scores.
    
        
    Morning/overnight HRV under similar conditions is most useful. You don't need to check HRV throughout the day.
