# Fenix Football — iPhone 17 Pro Max wallpaper

## Add your image

Save **your original photo** here as one of:

- `original.jpg`
- `original.png`

Then the agent (or you) can run:

```bash
python3 fenix-football-wallpaper/enhance_original.py
```

Outputs:

- `fenix-original-iphone17-pro-max.png` — full quality (1320×2868)
- `fenix-original-iphone17-pro-max.jpg` — smaller file for sharing
