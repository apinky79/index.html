Privacy & security

This app is designed so your order data stays on your device. There is no account, no subscription, and no company server receiving your forms.

What stays local

  • All form fields (To, From, order number, design, quantities, notes)
  • Cushion drawings and dimension labels
  • Saved drafts (stored in your browser’s localStorage on this iPad/computer only)

What never happens automatically

  • No data is uploaded to us or any third party
  • No analytics or tracking scripts
  • No advertising
  • No login or password stored

When data does leave your device

Only when you choose:

  • Export PDF — opens the print dialog; you save or share the PDF yourself
  • Browser features — if you bookmark, sync browser data via iCloud, or share a screenshot, that uses Apple/your browser’s own systems (not this app)

Offline use

After the first visit, the app can work offline via a service worker cache. Templates are loaded from the same website — no external CDN.

Security practices in the code

  • Content Security Policy restricts scripts and connections to this site only
  • No eval or third-party JavaScript
  • Open-source — you (or someone you trust) can read every file in the repository
  • Served over HTTPS when hosted on GitHub Pages

Clearing your data

Delete saved drafts from within the app, or clear this site’s data in Safari: Settings → Safari → Advanced → Website Data, find this site, and remove it.

Limitations

This is a browser tool, not medical or legal software. Always double-check measurements before sending orders to a workshop. Back up important PDF exports to iCloud or email yourself a copy.
